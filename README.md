# HumanAIOS

HumanAIOS is an AI-human orchestration platform. Workers complete real-world tasks delegated by AI agents. The platform is in pre-launch R&D.

This repository is the HumanAIOS core platform (zone Z-001). Its canonical practice seat is `empirica-foundation.carly.humanaios`.

## Repository layout

- `src/`, `apps/`, `agent/`, `supabase/` — platform code
- `docs/` — platform and integration documentation
- `operations/` — operational scripts and reference material
- `.empirica/` — practice configuration (`project.yaml` carries the registry project id)

## Evaluator documents

Governance documents for the empirica-foundation evaluator seat were removed from this repository. Their source of truth is the evaluator repository at https://git.getempirica.com/carly/empirica-foundation-evaluator. Where a file remains here as a pointer, it is a stub.
