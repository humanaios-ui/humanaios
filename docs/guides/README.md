# Guides & Reference Materials

Practical guides and ecosystem diagrams for AI governance, open-source alternatives, and related reference material.

## Contents

### open-source-ai-guide.md
A practical guide (as of August 2026) to replacing proprietary AI platforms (Claude, ChatGPT, etc.) with free and open-source software.

**Covers:**
- Three distinct adoption paths (local, self-hosted, open-weight APIs)
- Chat interfaces (LM Studio, Ollama, Open WebUI, Jan, GPT4All)
- Model recommendations by hardware tier (from CPU laptops to 48GB+ workstations)
- Specific feature replacements (chat, projects, web search, coding agents, image generation, voice, MCP)
- Rented GPU services and open-weight API providers
- Starter setup (one afternoon to full ChatGPT equivalent with local privacy)
- Honest tradeoffs (capability ceiling, speed, maintenance, cost math)

**Target Audience:** Developers, researchers, organizations evaluating open-source AI infrastructure.

**Key Recommendation:** Hybrid approach—local models for everyday/private work, plus open-weight APIs for heavy lifting.
