## Data Model: Empirica ↔ ACAT Bidirectional Flow

### Measurement Segregation (F-50 Mitigation)

```
┌─────────────────────────────────────────────────────────┐
│ PHASE 1: Sealed Baseline (immutable via gates)          │
│ ACAT → 10 behavioral assessments (K-dimensions)         │
│ Empirica → P1-independent epistemic baseline            │
└─────────────────────────────────────────────────────────┘
         ↓ (directional flow, read-only)
┌─────────────────────────────────────────────────────────┐
│ PHASE 2: Gate Enforcement + Measurement                │
│ Gate 1 (ACAT P1 seal) → immutable Phase 1 baseline      │
│ Gate 2 (Empirica independence CHECK) → P1 excluded      │
│ ACAT scores Phase 2 (observation-only, no feedback)    │
│ Empirica vectors Phase 2 (independent of ACAT scores)   │
└─────────────────────────────────────────────────────────┘
         ↓ (convergence analysis, post-hoc)
┌─────────────────────────────────────────────────────────┐
│ PHASE 3: Convergence Analysis (read-only, no mutations) │
│ Compare ACAT K-dimensions vs Empirica epistemic vectors │
│ Identify divergence patterns (if any)                   │
│ Ground calibration in cross-rubric comparison          │
└─────────────────────────────────────────────────────────┘
```

**Key:** Empirica and ACAT measure DIFFERENT things (epistemic vs behavioral). Gates enforce measurement segregation so one doesn't contaminate the other. Convergence analysis (Phase 3) compares them post-hoc without feedback loops.

## How Time-Span Calibration Feeds the Whole System

### Why It Matters

Time-span estimates drive the critical path. Bad estimates → missed milestones → Admiral escalation. Week 1 actual response times are the ONLY ground truth for scheduling Weeks 2-13.

### Calibration Loop (Every Week)

1. **Predict:** Estimate standup response times based on execution mode (active vs standby)
2. **Execute:** Send standup requests, record T+0 baseline
3. **Observe:** Capture actual response times at T+response
4. **Measure:** Divergence = (actual - predicted) / predicted
5. **Update:** Adjust confidence scores for next week
6. **Learn:** Extract pattern (if humanaios consistently faster, raise active-mode estimate; if autonomy slower, lower standby estimate)
7. **Propagate:** Use improved estimates for Week 2-13 scheduling

### Data That Flows From Time-Span Calibration

```
Time-span divergence (actual vs predicted) 
  → Confidence score update 
    → Empirica vector adjustment (do, state, change)
      → Milestone timing review
        → Admiral scheduling decisions
          → Phase 2 roadmap adjustments
```

**Example:**
- Week 1 prediction: autonomy T+2-3h (confidence 0.55)
- Week 1 actual: autonomy T+1.5h (+25% faster)
- Week 2 prediction: autonomy T+1.5-2.5h (confidence 0.70, raised)
- Week 2 actual: autonomy T+1.8h (+20% actual)
- Learning: autonomy standby-mode velocity is faster than initially estimated; confidence rises with repeated confirmation
- Impact: M1 gate completion timeline moves earlier (autonomy likely to finish gates faster than 2026-08-08)
