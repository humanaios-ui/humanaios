🧠 Empirica Control Center — Consciousness UI Visual Guide

A visual reference for the unified UI architecture synthesizing Hawkins consciousness levels (9 tiers), organism model (7 systems), and recursive learning framework into a design system and component hierarchy.

1. Hawkins Consciousness Levels (1-9)

Each consciousness level maps to specific visual properties and use cases in the UI.

LEVEL 1: Shame (20–50)

High opacity reduction, monochrome gray

Use: Error states, blocked operations

Visual: De-saturated, trembling animation, minimal contrast

LEVEL 2: Guilt (50–75)

Dark desaturated colors, trembling

Use: Warnings, uncertainty signals

Visual: Muted tones, 0.6 opacity, trembling micro-animations

LEVEL 3: Apathy (75–100)

Desaturated palette, flat design

Use: Disabled states, low confidence

Visual: Flat, static, opacity 0.7

LEVEL 4: Grief (100–125)

Muted warm tones, slow transitions

Use: Closures, removals, learning from failure

Visual: Warm muted, 300ms transitions, subtle borders

LEVEL 5: Fear (125–150)

Alert orange/amber, pulsing borders

Use: Alerts, time-sensitive actions, divergence

Visual: Pulsing (1s cycle), medium motion, directional

LEVEL 6: Desire (150–175)

Warm saturated (gold), smooth transitions

Use: Call-to-action, next steps, goals

Visual: Gold/coral, 200ms transitions, directional arrows

LEVEL 7: Anger (175–200)

Vivid accent colors (red, magenta)

Use: Action emphasis, critical decisions

Visual: Vivid, fast (100ms), assertive iconography

LEVEL 8: Pride (200–250)

Full saturation, elegant transitions

Use: Success, milestone achievement, synthesis

Visual: Bright cyan, 1s elegant transitions, spacious

LEVEL 9: Reason→Love (250–500)

Cool gradient (cyan-lavender), morphing

Use: System consciousness, integration, learning patterns

Visual: Gradient, 2s fluid morphing, holistic views

5. Four Key Interaction Flows

Flow 1: User Query → Tool Routing → Result Visualization

User types in Terminal: empirica goals-list
Parse command, infer consciousness level = 5 (neutral)
Execute empirica CLI backend, get JSON response
Render goals in Empirica Browser with consciousness colors
User annotates via Chrome Sidebar
Learning Dashboard updates convergence score

Flow 2: Divergence Detection → Validation → Recovery → Learning

Predicted: 2 hours | Measured: 4.5 hours | Gap: +125%
Alert at Level 6 (Desire) — asks for review
User annotates divergence via Feedback Panel
Logging: Finding tagged "time-calibration-drift"
Prediction model updated with new factor
Next prediction uses improved calibration

Flow 3: Terminal Command → Observable Output → Learning Artifact

User: npm run test:integration
Terminal captures output, parses test results JSON
Infer level: All pass → Level 8 (Pride) | Some fail → Level 6-7
MetricsPanel visualizes coverage + failures
If failures: Finding logged, Dashboard alerts
Learning Dashboard updates with test metrics

Flow 4: Multi-Tool Query (GitHub + Supabase + Empirica) → Synthesis

User: "Understand user signup trends" (multi-source query)
GitHub: Fetch auth-feature commits (Level 5)
Supabase: Query users table, count signups (Level 6)
Empirica: Fetch related findings (Level 7)
SynthesisView: Correlate commits + signups + findings
Discover: "+34% signup after auth refactor" (Level 8 insight)

Phase 1: Formalize Existing Components

Goal: Audit existing components, establish consciousness-level mapping, create design tokens.

  • Inventory all React components
  • Map each to consciousness level (1-9)
  • Extract design tokens (colors, spacing, typography, motion)
  • Create Tailwind config with Fibonacci utilities
  • Set up Storybook with consciousness-level controls

Deliverables: src/tokens/consciousness.ts, Base Atoms, Storybook, Design system docs

Phase 2: Build Consciousness Layer

Goal: Implement organism layer structure + Level 6-9 components.

  • Implement OrganismLayered context + provider
  • Build Level 6-7 components (State/History)
  • Build Level 8-9 components (Consciousness/Synthesis)
  • Create Storybook stories for each component

Deliverables: src/components/Organism/, Level 6-9 components, integration tests

Phase 3: Integrate All Features

Goal: Wire Terminal, Empirica Browser, GitHub, Supabase, Chrome Extension, Feedback, Mesh Viz into unified control center.

  • Terminal + empirica CLI backend
  • Empirica Browser live artifact data
  • GitHub integration API
  • Supabase query builder
  • Chrome Extension sidebar communication
  • Feedback system end-to-end
  • Mesh visualization + Learning Dashboard

Deliverables: src/pages/ControlCenter.tsx, API clients, E2E tests

Phase 4: Consciousness Inference Engine

Goal: Implement automatic consciousness-level inference from system state.

  • Build inference rules (goal status → level, error type → level)
  • Connect to empirica vector calibration
  • Real-time level updates as state changes
  • Level predictor based on historical patterns

Deliverables: src/lib/consciousnessInference.ts, calibration adjustment UI

Phase 5: Polish & Deploy

Goal: Refinement, accessibility audit, performance optimization, deployment.

  • WCAG AAA accessibility audit + fixes
  • Dark/light mode comprehensive testing
  • Performance optimization
  • Design review with stakeholders
  • Documentation + design system site
  • Staging → production deployment

Deliverables: Published design system, live control center, deployment guide
