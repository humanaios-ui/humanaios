# Pre-Registration — Convergent Self-Accountability Study v1.0
# FROZEN before any coding. Two independent rubrics + decision rules. Session S-082226.

## RUBRIC A — Inclusion checklist (coded BLIND to independence)
A system is INCLUDED iff all four necessary features are present:
  A1 periodic cadence      — recurring review at a defined interval (daily/per-cycle/per-event)
  A2 graded external code   — an explicit standard/code the self is measured AGAINST (not free reflection)
  A3 review-against-code    — an explicit step comparing conduct to the code
  A4 correction loop        — a defined mechanism to correct/amend based on the review
Score each 1/0. INCLUDE only if A1+A2+A3+A4 = 4. Coded without reference to lineage.

## RUBRIC B — Independence coding (applied only to INCLUDED systems)
Two pre-registered passes to expose coder-dependence:
  STRICT  — collapse any candidate with PLAUSIBLE transmission contact into its parent lineage
            (burden: independence must be demonstrable; contact presumes descent)
  LENIENT — collapse only candidates with DEMONSTRATED direct transmission
            (burden: descent must be demonstrable; absent proof, presume independent)
Report BOTH N_strict and N_lenient. Agreement between passes = the inter-rater proxy.

## Decision rules (pre-committed, from the operator's draft)
  From 10 candidates: collapse of >2 affirms H1; collapse of >=5 affirms H0.
  Primary: reject H0 if provenance-coded N >= 8 (cumulative binomial vs baseline).

## Statistical model
  Trials n = major independent cultural regions x millennia of documented record.
  Pre-registered n = 21 (7 regions x 3 millennia); reported with n-sensitivity {15,21,28}.
  Baseline p = 0.15 per region-millennium (operator-supplied; UNSOURCED — flagged).
  p-sensitivity pre-registered: {0.05,0.10,0.15,0.20,0.25,0.30}.
  Test: P(X >= N | n, p), cumulative binomial upper tail.

## Pre-commitments (honesty locks)
  - N is reported regardless of which hypothesis it favors.
  - If N_strict and N_lenient give OPPOSITE verdicts, the result is declared
    NOT-ROBUST (coder-dependent), not a confirmation of either hypothesis.
  - Single-model coding is NOT true inter-rater reliability; flagged as a limitation.
  - The AI-verification candidate is the coder's own program (reflexivity) — flagged.
