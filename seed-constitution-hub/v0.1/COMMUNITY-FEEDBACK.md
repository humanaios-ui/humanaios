## How This Feedback Loop Works

**Every Friday, 5pm PT:**
1. **Aggregate** — Poll Substack comments, INTENT-OS export, GitHub issues from past 7 days
2. **Anonymize** — Remove personally identifiable information (keep org/community affiliation if shared)
3. **Classify** — By Principle (1–9) + cross-cutting theme
4. **Summarize** — Patterns, top questions, opportunities
5. **Report** — Email to Carly + GitHub commit (this file)

**Carly reviews (by Monday):**
1. Read synthesis report
2. Decide: publish response on Substack? Update DECISION-LOG.md? Adjust research? Defer to v0.2?
3. Log decision

**Research adjusts (by Thursday):**
- Next ACAT post responds to top community questions
- Constitution posts reference community inbound
- GitHub threads show decision + rationale

**Cycle repeats:** Next Friday.

## What Counts as "Feedback"

**High-value feedback:**
- Direct questions about Principles ("How does Principle 5 scale to small orgs?")
- Implementation challenges ("We tried Principle 3 and ran into X")
- Thoughtful disagreement ("Principle 7 seems unclear; here's why")
- Comparative questions ("How does this differ from AEGIS's approach?")

**Low-value feedback** (logged but not acted on):
- Off-topic comments
- Spam
- Duplicate questions (synthesized into single pattern)
- Vague affirmations ("Love this!")

---

## Privacy & Anonymization

**We keep:**
- Community/org affiliation (if shared)
- General topic area
- Sentiment (question vs. challenge vs. agreement)
- Specific quotes (with attribution anonymized)

**We remove:**
- Names, emails, usernames
- Company-specific details that could de-anonymize
- Personal information

**Exception:** If someone wants attribution (explicitly "please use my name"), we honor that.
